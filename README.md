# The Craving Kitchen

Crie uma landing page completa, mobile-first e altamente focada em conversão para o produto digital chamado “Mata Vontade”.

IMPORTANTE:

Não quero uma página genérica de ebook fitness.

Quero aparência de uma marca gastronômica moderna, premium, extremamente apetitosa e visual.

A ideia central do produto é:

“Receitas para matar aquela vontade de pizza, hambúrguer, salgado, chocolate e doce sem precisar viver de comida sem graça.”

A página precisa transmitir:

- prazer

- comida gostosa

- desejo

- praticidade

- facilidade

- modernidade

- sensação de produto premium

- zero aparência de “dieta restritiva”

DESIGN SYSTEM

Paleta principal:

- Laranja principal: #FF7424

- Vermelho coral: #E9472B

- Chocolate espresso: #281712

- Creme quente: #FFF5E9

- Branco: #FFFFFF

Cores auxiliares:

- Pêssego: #FFD9C3

- Dourado: #F5B83B

- Verde segurança: #174C3B

Use principalmente:

55% creme/branco

20% chocolate escuro

15% laranja

7% vermelho coral

3% dourado/pêssego

O degradê oficial da marca deve ser:

linear-gradient(135deg, #FF7424 0%, #E9472B 100%)

TIPOGRAFIA

Quero tipografia grande, moderna, forte, arredondada e amigável.

Headlines:

- bold

- alto impacto

- pouco espaçamento

- visual moderno de marca de alimentação

Textos:

- extremamente legíveis

- frases curtas

- mobile-first

Evite fontes com aparência corporativa ou formal demais.

ESTILO VISUAL

A página deve lembrar uma marca gastronômica contemporânea, não um ebook antigo.

Use:

- bastante espaço em branco

- cards grandes

- bordas arredondadas entre 24px e 34px

- sombras suaves

- imagens de comida grandes

- pequenas tags coloridas

- ícones minimalistas

- seções alternando creme, branco e chocolate escuro

As fotografias de comida devem ser protagonistas.

Priorizar imagens extremamente apetitosas de:

- pizza com queijo puxando

- hambúrguer

- brownie cremoso

- cookie com chocolate

- coxinha

- pastel

- sobremesas

- lanches

- batata crocante

Evitar estética fitness clichê:

- folhas verdes demais

- balança

- fita métrica

- corpo fitness

- salada como protagonista

EFEITOS VISUAIS E ANIMAÇÕES

==================================================

Quero efeitos visuais modernos, mas NÃO quero uma página pesada ou cheia de animações exageradas.

Prioridade:

performance + conversão.

Implementar:

1. Reveal on scroll

Cada seção deve entrar suavemente conforme o usuário rola.

Utilizar:

opacity 0 → 1

translateY(25px) → 0

Duração:

aproximadamente 500–700ms.

2. Stagger animation

Cards de categorias devem aparecer sequencialmente.

3. Parallax suave

Em algumas imagens grandes de comida, fazer um pequeno movimento vertical diferente do scroll.

Muito sutil.

4. Zoom de imagens

Fotos de comida podem ter scale 1 → 1.03 ao aparecer ou no hover.

5. Botões

CTA deve ter:

- microanimação no hover

- pequeno scale

- glow extremamente discreto

- transição suave

6. Sticky CTA no mobile

Depois que o usuário passar do hero, mostrar uma barra discreta fixa na parte inferior com:

“Mata Vontade por R$ 7,90”

[QUERO AGORA]

Ela deve desaparecer quando estiver sobre a seção principal de compra para não duplicar botões.

7. Scroll progress

Criar uma linha fina de progresso no topo da página que avance conforme o scroll.

Usar o degradê laranja → vermelho.

8. Imagens em camadas

No hero, criar pequenos movimentos independentes para pizza, brownie e hambúrguer conforme o mouse ou scroll.

Muito sutil.

9. Cards

Ao passar o mouse:

translateY(-4px)

sombra aumenta levemente.

No mobile:

usar animação ao entrar no viewport.

10. Texto destacado

Algumas palavras em laranja podem receber underline desenhado ou highlight animado ao aparecer.

11. Números

Quando aparecer “120+ receitas”, criar count-up:

0 → 120+

12. FAQ

Accordion com abertura e fechamento suaves.

13. Smooth scroll

Todos os links internos devem usar scroll suave.

==================================================

SCROLL E EXPERIÊNCIA MOBILE

==================================================

A página será majoritariamente acessada por celular.

Portanto:

- construir MOBILE-FIRST

- evitar blocos de texto grandes

- no máximo 2–4 linhas por parágrafo

- botões grandes

- títulos fortes

- imagens ocupando bastante espaço

- cards fáceis de deslizar

- espaço de toque confortável

- excelente performance

No mobile:

cards podem aparecer em scroll horizontal quando isso melhorar a experiência.

Evitar páginas extremamente longas apenas por decoração.

Cada seção deve ter uma função de conversão clara.

==================================================

PERFORMANCE

==================================================

Extremamente importante:

Não usar animações pesadas que prejudiquem Core Web Vitals.

Usar:

- lazy loading de imagens

- WebP/AVIF quando possível

- animações por transform e opacity

- evitar vídeos autoplay pesados

- evitar JavaScript excessivo

- evitar bibliotecas enormes apenas para animações

Respeitar:

prefers-reduced-motion

Se o usuário tiver redução de movimento ativada, remover parallax e animações intensas.

==================================================

DETALHES IMPORTANTES DE CONVERSÃO

==================================================

Não transformar a página em uma VSL escrita longa.

Ela deve ser altamente escaneável.

A lógica da página é:

DESEJO

→ COMIDA

→ CATEGORIAS

→ PRODUTO

→ BÔNUS

→ PREÇO

→ PROVA

→ GARANTIA

→ CTA

Não colocar longas seções de:

- dor

- medo

- explicações sobre dieta

- textos científicos

- storytelling excessivo

As imagens e os nomes das comidas devem vender o desejo.

Quero que alguém consiga rolar rapidamente a página e entender a oferta sem precisar ler todos os textos.
